Project Documentation

This section makes the application presentable as a 3rd year BTech CSE project by clearly showing objectives, methodology, and future scope.

Problem Statement

Phishing and smishing attacks trick users into submitting credentials, OTPs, or financial information. This project detects suspicious links and SMS messages using explainable rule-based features and local evidence logging.

Objectives

  • Detect phishing URLs using lexical and domain-based features.
  • Detect smishing messages using suspicious intent patterns.
  • Generate explainable risk scores and evidence reports.
  • Guide users through an AI-style security assistant.
  • Provide analytics and awareness guidance for users.

System Architecture

Input LayerURL, SMS, pasted text, and QR scan input.
PreprocessingNormalization, URL parsing, keyword extraction, and feature generation.
Detection EngineWeighted rules plus brand similarity scoring.
AI Assistant LayerContext-aware guidance that explains verdicts, safety actions, and project logic.
Output LayerVerdict, dashboard, scan history, assistant guidance, and PDF report.
